## 1. Objective

To understand how multiple numerical input features can be used to predict a continuous target using multiple linear regression.

The activity includes manual calculation of regression coefficients, model development using Python, comparison with a single-feature model, interpretation of coefficients, residual analysis, multicollinearity checking, and prediction of a new example.

## 2. Dataset Description

**Dataset:** California Housing Dataset

**Dataset Source:** https://www.dcc.fc.up.pt/~ltorgo/Regression/cal_housing.html

**Documentation:** https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_california_housing.html

The dataset contains information about housing districts in California. It includes household income, average rooms, house age, population, and geographical information.

- **Observations:** 20,640
- **Input Features:** 8
- **Total Columns:** 9, including the target
- **Target Variable:** MedHouseVal
- **Target Units:** $100,000

### Input Features

1. MedInc – Median household income
2. HouseAge – Median house age
3. AveRooms – Average number of rooms
4. AveBedrms – Average number of bedrooms
5. Population – District population
6. AveOccup – Average household occupancy
7. Latitude – Geographical latitude
8. Longitude – Geographical longitude
